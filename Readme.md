# 💰 Expense Tracker

A professional web-based Expense Tracker built using HTML, CSS, and JavaScript.

It allows users to track income and expenses month-wise, manage budgets, and view financial analytics with AI-based spending insights.

---

## 🚀 Features

- 📅 Date picker with month-wise filtering
- 📊 Dashboard cards (Balance, Income, Expense, Savings %)
- 📈 Category-based analytics chart
- 🔔 Overspending alert popup
- 💰 Monthly budget system
- 🤖 AI spending suggestions
- 📋 Transaction history (saved permanently)
- 🔄 Sort transactions (Latest / Oldest)
- 🗑 Reset all data option
- 💾 LocalStorage data persistence

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Chart.js
